# AI-Powered House Price Predictor 🏠

An interactive end-to-end Machine Learning web application built using Python, Scikit-Learn, and Streamlit as part of **Module 5: AI Tools & Mini Project**.

## Overview
This application upgrades a baseline regression model into a user-friendly decision-support tool. It predicts real estate prices based on architectural attributes, location profiles, and building conditions while generating automated valuation insights.

## Features
- **Interactive UI:** Dynamic sliders and controls powered by Streamlit.
- **Trained ML Backend:** Random Forest Regressor trained on historical property data.
- **Smart Insight Generator:** Automated appraisal summary breakdown.
